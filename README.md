# 面试准备

面向 Cloud Native、Kubernetes Platform 与 AI Infra 研发岗位的长期学习项目。

## 学习循环

> 原理 → 源码/代码 → 实验 → 故障现象 → 面试题 → 自己讲一遍

不要机械地从 00 学到 19。算法每天持续练习，其余内容按主干与分支交叉推进。

| 优先级 | 领域 |
| --- | --- |
| 第一梯队 | Linux、Network、Kubernetes、Kubernetes Development、Distributed Systems、AI Infra |
| 第二梯队 | Go、Container Runtime、Kubernetes Networking、System Design、Troubleshooting |
| 第三梯队 | Storage、Observability、Security、Database / MQ、Cloud Native Ecosystem |

## 环境建议

- Mac：编辑器、Go、kubectl 和日常开发。
- Podman：普通容器与部分 Kubernetes 实验。
- Ubuntu Linux VM：Kernel、namespace、cgroup、netfilter、tc、eBPF、CNI 等底层实验。
- GPU、RDMA、NCCL 等实验需要时再使用具备相应硬件的真实 Linux 环境。

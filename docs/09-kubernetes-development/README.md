# 09 Kubernetes Development

## 学习目标

掌握 Kubernetes API 客户端、缓存、队列、控制循环和 Operator 开发。

## 知识清单

- API Machinery
- client-go
- RESTClient
- List / Watch
- Reflector
- DeltaFIFO
- Informer
- Indexer
- WorkQueue
- Controller
- controller-runtime
- CRD
- Operator
- Leader Election

## 实践建议

按 CRD → client-go → Informer → WorkQueue → Controller → controller-runtime → Operator 推进。

# 14 Distributed Systems

## 学习目标

理解故障、不确定性和一致性权衡，并能用于系统设计与组件分析。

## 知识清单

- CAP / PACELC
- consistency models
- logical clock
- replication
- quorum
- Raft
- Paxos
- leader election
- distributed lock
- lease / fencing
- 2PC / Saga
- idempotency
- retry / timeout
- failure detection

## 实践建议

用时间线和故障注入解释各算法的安全性、活性、边界和工程取舍。

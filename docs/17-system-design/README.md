# 17 System Design

## 学习目标

把分散知识串成可落地、可扩展、可观测和可演进的 Infra 系统设计。

## 知识清单

- scalability
- load balancing
- cache
- queue
- rate limiting
- service discovery
- configuration
- HA
- disaster recovery
- Cloud Native 系统设计题

## 练习题

- 设计容器平台
- 设计百万 Pod 的 Kubernetes 管理平台
- 设计 GPU 调度平台
- 设计配置中心、监控系统或跨集群调度系统

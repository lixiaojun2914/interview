# 03 操作系统与 Linux Kernel

## 学习目标

理解容器与云原生系统依赖的操作系统机制，并能够通过实验观察行为。

## 知识清单

- Process / Thread
- syscall
- scheduler
- virtual memory
- page / page cache
- mmap
- filesystem / VFS
- IO
- namespace
- cgroup v1/v2
- capabilities
- seccomp
- container fundamentals

## 实践建议

底层实验优先放在 Linux VM，配合 `strace`、`perf`、`/proc` 和 cgroup v2 文件系统观察。

# 07 Kubernetes Core

## 学习目标

理解控制平面、节点组件、对象生命周期以及高可用机制。

## 知识清单

- Architecture
- API Server
- etcd
- Scheduler
- Controller Manager
- kubelet
- Pod lifecycle
- Deployment / ReplicaSet / StatefulSet
- Service
- RBAC
- Admission
- CRD
- Scheduler Framework
- HA

## 实践建议

每类对象都结合 API 行为、控制循环、事件、状态迁移和故障场景学习。
